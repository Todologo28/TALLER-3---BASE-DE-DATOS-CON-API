Caso de Uso

🏪 Sistema de Gestión de Proveedores — MedPanamá S.A.

Actor Principal: Departamento de Compras
Sistema: API REST de Proveedores
Objetivo: Gestionar el ciclo de vida completo de los proveedores médicos.

📋 Flujo Principal: 1. El encargado de compras abre el sistema y consulta (GET) todos los proveedores activos.
2. Recibe oferta de nuevo proveedor y lo registra (POST) con sus datos.
3. El proveedor cambia número de teléfono; se actualiza (PUT) la información.
4. El proveedor deja de operar; se elimina (DELETE) del sistema.
5. En todo momento se puede buscar (GET ?q=) por nombre o categoría.

Simulación del Caso de Uso

Ejecuta el caso de uso paso a paso como lo haría el departamento de compras de MedPanamá:

PASO 1 — GET /api/proveedores

Consultar proveedores activos del área médica en el sistema.

PASO 2 — POST /api/proveedores

Registrar nuevo proveedor: "Equipos Médicos del Istmo".

PASO 3 — PUT /api/proveedores/{id}

Actualizar teléfono del proveedor MediSupplies (ID 5).

PASO 4 — GET /api/proveedores/1

Consultar detalle de un proveedor específico antes de operar.
